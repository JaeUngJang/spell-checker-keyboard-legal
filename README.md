# Spell Checker & Translator: Keyboard

A custom iOS keyboard for anyone writing in a second language. You keep typing with the keyboard you already use; when you want a second look, switch to Spell Checker and tap Check to fix spelling, grammar and wording in the language you wrote in, or Translate to turn it into the language you choose, in the tone you set.

Coming soon to the App Store.
